Scam With Your Friends Mods (SWYF)

Neoficiální Scam With Your Friends mods pro české a slovenské hráče. Balíčky používají BepInEx a instalují se přes formát .swyfmod.

Unofficial SWYF mods for Czech and Slovak players, focused on better speech recognition, Czech TTS and privacy.

Download mods Install SWYF Mod Hub GitHub source

Available Scam With Your Friends mods

CzechSpeechEnhanced

Improved Czech and Slovak speech recognition using NVIDIA Parakeet TDT v3 or Parakeet Ultra. The mod gives natural speech pauses more time before finalizing a sentence.

CzechTTSFix

Fixes Czech text preprocessing for the game's TTS so NPC speech keeps Czech diacritics and better punctuation.

PrivacyTelemetry

Blocks known game analytics and reduces selected diagnostic data included in feedback.

Installation

  1. Install SWYF Mod Hub by Dex. It installs BepInEx and handles .swyfmod files.
  2. Download the mod from GitHub Releases.
  3. Install the .swyfmod package through SWYF Mod Hub and restart Scam With Your Friends.
