Časté otázky

Krátce k instalaci a použití modů.

Jak nainstalovat mody do Scam With Your Friends?

Nainstaluj SWYF Mod Hub od Dexe, stáhni .swyfmod z GitHub Releases, nainstaluj ho přes Mod Hub a restartuj hru.

Který mod zlepšuje rozpoznávání češtiny a slovenštiny?

CzechSpeechEnhanced. Může používat Parakeet TDT v3 nebo Parakeet Ultra.

Jak opravit českou výslovnost NPC?

CzechTTSFix upravuje český text před herním TTS, aby se zachovala diakritika a správněji zpracovala interpunkce.
